## Linz Netz Analyse Tool

Bei der Mitgliederversammlung wurde mehrfach die Möglichkeit zur Eingenverbrauchsanalyse angesprochen. Dafür möchten wir eine vollständig lokale Lösung anbieten, in der Sie den CSV-Export der Linz Netz Daten visualisieren können.
Das Tool wird als eine _lokale Webseite_ angeboten. Laden Sie die [HTML-Datei](https://github.com/4e-schwertberg/linz-netz-analyse/releases/latest/download/linz-netz-analyse.html) herunter. Diese öffnet sich im Browser.
Danach wählen Sie eine CSV-Datei aus, die Sie zuvor vom [Portal der Linz Netz](https://www.linznetz.at/portal/de/home) unter dem Menüpunkt [_Verbrauchsdaten_](https://www.linznetz.at/portal/de/home/online_services/serviceportal/verbrauchsdateninformation_1/verbrauchsdateninformation.html) exportiert haben.
